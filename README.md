# Pizza_Sales_Analysis
# 🍕 Pizza Sales Analysis (SQL Project)

## 📌 Project Overview
This project analyzes a pizza sales dataset using SQL to extract meaningful patterns related to orders, revenue, and product performance.

The goal is to practice and demonstrate skills in:
- Data querying
- Aggregation
- Joins
- Window functions
- Analytical thinking

---

## 🛠️ Tech Stack
- SQL (MySQL)
- Relational Database Concepts

---

## 📂 Dataset Description
The dataset consists of the following tables:

- **orders** → contains order date and time  
- **order_details** → contains quantity and pizza IDs  
- **pizzas** → contains pizza size and price  
- **pizza_types** → contains pizza name and category  

---

## 📊 Key Analyses Performed

1. Total number of orders placed  
2. Total revenue generated  
3. Highest priced pizza  
4. Most common pizza size  
5. Top 5 most ordered pizzas  
6. Quantity of pizzas by category  
7. Orders distribution by hour  
8. Category-wise pizza distribution  
9. Average pizzas ordered per day  
10. Top 3 pizzas by revenue  
11. Percentage contribution by category  
12. Cumulative revenue over time  
13. Top 3 pizzas by revenue within each category  

---

## ⚙️ Concepts Used

- `JOIN` (INNER JOIN)
- `GROUP BY`
- Aggregate functions (`SUM`, `COUNT`, `AVG`)
- Window functions (`ROW_NUMBER()`, `DENSE_RANK()`)
- Common Table Expressions (CTEs)
- Date & time functions
